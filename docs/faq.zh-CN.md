# FAQ 与故障排查

[English](faq.md) | **简体中文** · [文档目录](README.zh-CN.md)

## 每条消息都会自动换模型吗？

不会。消息先交给当前主模型；Skill 只为确有必要的子任务建议受支持的模型，没有请求前拦截层。

## 每次都要提到 Skill 吗？

允许隐式调用，Codex 可在任务匹配时加载它；这不是每条消息必定执行的触发器，加载也不代表启动代理。明确想用这套工作流时可以写 `$workspace-router`。

## 我是订阅用户，需要另外付 API 费用吗？

规则脚本和控制台不调用模型 API，也不需要单独的 Router Key。真实子代理使用当前 Codex 会话已有的能力，可用性和用量取决于账号及运行环境。尚未测得订阅额度节省比例。

## 为什么经济方案仍选 Sol 或 Astra？

Luna 试用要求需求精确、有实质测试、局部文本任务、边界清楚、低风险和低不确定性全部成立。其他任务按已有档位处理，高影响任务仍保持关键档。[查看全部条件](../workspace-router/references/presets.zh-CN.md)

## 找不到 Skill

检查实际执行主机、客户端支持的发现目录，以及目录内是否有 `SKILL.md`；避免同名重复安装。新建任务，发现未刷新时再重启客户端。[部署详情](installation.zh-CN.md)

## 保存了，为什么效果没变？

查看控制台**配置来源**。普通启动编辑仓库示例；`--installed` 编辑配套安装器的目标；手动安装需要 `--policy`。新配置影响之后重新读取文件的决策，不改变已经派发的代理；SSH 主机需要分别安装配置。

## 模型不可用，或模拟与实际不同

模拟使用假设能力集，不检查订阅或远端。实际路由要求当前主机支持相同模型与强度；明确指定但不可用的路线会报告限制。关键档没有受支持路线时，主代理需解决限制后才能宣称通过关键验收。

## 控制台版本不匹配、访问失败或保存冲突

- **版本不匹配：** 用同一份已审阅源码升级 Skill 和控制台，保留私人工作区说明。
- **访问失败：** 打开本次启动打印的完整 URL，包含临时令牌；不要公开该链接。
- **保存冲突：** 先导出需要保留的草稿，重新载入当前文件，再应用预期修改。

## 控制台必须一直开着吗？

只有编辑和模拟时需要。保存后可以关闭；Skill 读取已保存文件，控制台不是常驻路由服务。

## 能控制浏览器和远程电脑吗？

Router 不增加工具。浏览器、电脑和 SSH 操作仍取决于当前 Codex 的权限与能力；共享交互操作由主代理处理。
